# Probabilistic-Analysis-of-Password-Strength-Using-Statistical-Methods


## Overview
This project analyzes password strength using probability and statistics.  
It estimates how likely a password can be guessed using brute-force and dictionary attacks.

---

## Objectives
- Define password strength mathematically  
- Model password generation using probability  
- Calculate entropy and guessing probability  
- Simulate brute-force & dictionary attacks  
- Compare weak, medium, and strong passwords  

---


## Method

### 1. Dataset
- Weak → common passwords  
- Medium → mix of letters & numbers  
- Strong → random characters  

### 2. Entropy Formula
H = -Σ p(x) log2 p(x)

Higher entropy = stronger password

### 3. Attacks
- Brute-force → tries all combinations  
- Dictionary → uses common passwords  

---

## Conclusion
Strong passwords have higher entropy and are much harder to guess, while weak passwords are easily broken.
